# Internationalization (i18n)

**Overview:**
- Full internationalization support for POS frontend with English, Arabic, and French translations
- Vue i18n integration with dynamic locale switching
- RTL (Right-to-Left) support for Arabic language
- All user-facing strings moved to translation files

**Translation Files:**
- Location: `src/libs/i18n/locales/`
- Files: `en.json`, `ar.json`, `fr.json`
- Structure: Organized by feature/page sections (e.g., `pos.payment`, `pos.itemSelection`, `admin.returnsManagement`)

**Translated Pages:**
1. **Login Page** (`Login.vue`):
   - Brand name, welcome message, form labels, placeholders, buttons
   - Language switcher dropdown with flag icons
   - UI enhancements: gradient welcome title, smooth animations, dark mode support

2. **Open Session** (`OpenSession.vue`):
   - All labels, placeholders, buttons, error messages
   - Auto-redirect to items page if session already open

3. **Item Selection** (`ItemSelection.vue`):
   - Page header, search, navigation breadcrumbs, cart summary
   - All modals: Pending Tickets, Close Session, Discount
   - Virtual keyboard labels, error messages, toast notifications
   - Dynamic table fields converted to computed properties for translation

4. **Payment** (`Payment.vue`):
   - Summary panel, payment methods, payment cards
   - Discount dialog with all labels and preview text
   - Action buttons, error messages, success notifications
   - Voucher validation messages

5. **Return Products** (`ReturnProducts.vue`):
   - Ticket search, ticket details, return items table
   - Return type selection, return summary
   - All validation and error messages
   - Print voucher messages

6. **Customer Management** (`CustomerManagement.vue`):
   - Shared component for both `/pos/customers` and `/admin/customers`
   - Conditional "Set as Default" feature (admin only, removed for POS users)
   - Table headers, filters, modals, error messages
   - Status filter options dynamically translated

7. **Admin Pages:**
   - Tickets History: All filters, table headers, modal details
   - Returns Management: Full page translation
   - Item Barcodes: Search, filters, table, item details
   - Item Families: CRUD modals, table headers
   - Item Subfamilies: CRUD modals, table headers
   - Session History: Modal details, error messages

**Key Implementation Details:**
- **Computed Properties**: Table fields, filter options, and dynamic labels converted to computed properties for real-time translation
- **RTL Support**: CSS adjustments for Arabic (RTL) layout, including modal close button padding
- **Language Switcher**: Login page includes dropdown with flag icons for language selection
- **Session Check**: Open Session page checks for existing session and redirects automatically
- **Conditional Features**: Customer Management shows/hides features based on user role (admin vs POS user)
- **Toast Notifications**: All toast messages use translation keys with interpolation for dynamic values
- **Error Messages**: All error messages translated with proper context

**Translation Key Structure:**
```json
{
  "pos": {
    "itemSelection": { ... },
    "payment": {
      "buttons": { ... },
      "errors": { ... },
      "success": { ... },
      "headerDiscount": { ... }
    },
    "returnProducts": {
      "tableHeaders": { ... },
      "errors": { ... },
      "success": { ... }
    },
    "customerManagement": {
      "tableHeaders": { ... },
      "statusFilterOptions": { ... },
      "errors": { ... },
      "success": { ... }
    }
  },
  "admin": { ... },
  "common": { ... }
}
```

**Vue i18n Usage:**
- Template: `{{ $t('pos.payment.back') }}`
- Script: `this.$t('pos.payment.errors.failedToComplete')`
- Interpolation: `this.$t('pos.payment.success.saleCompletedText', { number: salesNumber })`
- Pluralization: `{{ $t('pos.customerManagement.customer', { count: totalRows }) }}`

**RTL Styling:**
- `document.documentElement.dir` set to 'rtl' for Arabic
- CSS adjustments in `src/assets/scss/style.scss` for RTL layouts
- Modal close button padding adjusted for RTL
- All layouts tested and working in RTL mode
